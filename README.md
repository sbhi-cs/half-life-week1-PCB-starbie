# half-life-week1-PCB-starbie
This is my week 1 starbie tutorial project. I've never worked with hardware stuff before so hoping this goes well :D

The repo includes the Arduino code (.ino), the schematic diagram of the PCB, and the gerber file of the PCB

I sort of changed it midway through to not be related to starbie but rather my own little character

The project is still the same though: a custom tamagotchi

I made this project because I think tamagotchis are awesome. I also wanted to learn basic hardware and PCB stuff, and make something of my own!
When I realized half-life was doing a tutorial on how exactly this is made, I instantly wanted to make one for myself, since I would be learning something new.
Through making this, I learned how to use KiCad, and the process of making and routing a PCB.
It's still sort of confusing but I'm getting somewhere atleast!

## How am I making this though?
100% honesty, I have no clue.
I don't have soldering equipment,, I don't know how I'm gonna assemble it, and I don't know how to import the .ino file into the microcontroller
I'm just waiting on the parts so I can start, since doing is the best way to learn :D
(This is being severely carried by the tutorial if there will be one in week 6)
